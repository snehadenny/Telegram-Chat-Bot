# Telegram-Chat-Bot
A Python-based Telegram chatbot that automatically receives user messages, processes them using a custom AI engine, and sends intelligent replies in real time through the Telegram Bot API. Built using polling, request handling, and automated message response features.

Technologies

Python
Telegram Bot API
Requests Library (requests)
Time Module (time)
Polling Mechanism
REST API
JSON Data Handling
Custom AI Engine (aiengine)

Features

Real-time automated messaging
AI-based response generation
Continuous message monitoring
Simple and lightweight chatbot system

The Process

The chatbot continuously checks for new Telegram messages using the Telegram Bot API. When a user sends a message, the bot receives it, processes the text through the custom AI engine, generates a reply, and automatically sends the response back to the user in real time.

Running The Project

1.Install Python on your system
2.Install required library:
//pip install requests
3.Create a Telegram bot using Telegram and get the Bot Token from BotFather
4.Add the bot token in the Python code
5.Run the program:
//python bot.py
6.Open Telegram, send a message to your bot, and the chatbot will automatically reply.
